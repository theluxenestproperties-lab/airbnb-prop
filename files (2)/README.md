# Luxenest Hazeldean proposal (GRL151)
Files: index.html, styles.css, app.js, assets/ (cropped GProps listing photos).
## Deploy to GitHub Pages
1. Create a GitHub repository and upload everything in this folder to the repository root.
2. Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`, Save.
3. After a minute or two the site appears at `https://<username>.github.io/<repo>/`. It is not live until you have done this.
Edit assumptions in app.js (budget list, scenario rates) and text in index.html.
